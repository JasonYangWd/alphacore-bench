# AlphaCore Bench

A browser-based simulator for the AlphaCore hexagonal teaching board from the **RECODE** trilogy — drag
modules onto its edges, build composite modules in the editor, write `setup()`/`loop()` code, and watch it
run. No install, no account, nothing leaves your browser.

▶️ **[Try it live](https://jasonyangwd.github.io/alphacore-bench/)**

📖 **[Full wiki](https://github.com/JasonYangWd/alphacore-bench/wiki)** — how to use the Bench, plus links to the story.
